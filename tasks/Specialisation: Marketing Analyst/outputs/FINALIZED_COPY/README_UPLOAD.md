# Marketing Campaign Comparison - Upload Files

Use these files for the Marketing Analyst final task:

1. `marketing_campaign_duration_dashboard.xlsx`
   - Excel visualization workbook.
   - Contains dashboard visuals, two large chart sheets, BigQuery result data, campaign summary, chart helper data, and README tab.

2. `marketing_campaign_comparison_presentation.pptx`
   - Story-led PowerPoint presentation.
   - Explains the decision, session logic, visual findings, sample-size caution, limitations, and recommended next analysis.
   - The first slide follows the Product Analyst title-slide style and does not include KPI cards.

3. `marketing_campaign_comparison_speaker_notes.md`
   - Speaker notes for the presentation.
   - Use this to practice explaining each slide in review.

4. `marketing_campaign_comparison_session_duration.sql`
   - SQL code file.
   - Creates modeled sessions and summarizes average session duration by campaign and weekday.

Supporting files are also included:

- `marketing_campaign_weekday_duration.csv`: BigQuery export used for the Excel dashboard and presentation.
- `marketing_campaign_comparison_findings.md`: written summary of findings, drawbacks, and recommendations.

Important interpretation:

- Referral traffic has longer sessions than organic traffic across the week.
- Data Share Promo has the longest reliable weighted average session duration, but fewer sessions than organic and referral traffic.
- Black Friday and holiday campaign averages should not be overclaimed because their sample sizes are very small.
