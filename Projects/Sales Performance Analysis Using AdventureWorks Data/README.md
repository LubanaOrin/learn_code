# Sales Performance Analysis Using AdventureWorks Data

## Project Overview

This project analyzes AdventureWorks sales data in Excel to create a business-facing sales performance overview.

The workbook focuses on monthly sales trends, online versus non-online sales, delivery performance, top salespeople, top countries, and sales reasons. The goal was to turn raw sales tables into a clear dashboard-style overview that supports business review and discussion.

## Main Deliverable

- `Sales Performance Analysis Using AdventureWorks Data.xlsx`: Excel workbook with the dashboard, pivot tables, charts, formulas, and source tables.

## Business Questions

The analysis answers these questions:

1. What is the monthly sales trend?
2. How do online and non-online sales compare?
3. How does delivery performance change over time?
4. Which salespeople perform best by sales and order volume?
5. Which countries generate the most sales?
6. What are the main sales reasons?

## Workbook Structure

The workbook includes:

- `Overview`: main dashboard and business summary.
- `Pivots 1` to `Pivots 7`: supporting pivot-table analysis.
- `AdventureWorks.SalesOrderHeader`: order-level sales data.
- `AdventureWorks.SalesReason`: sales-reason lookup data.
- `adventureworks.Employee`: salesperson and employee data.
- `AdventureWorks.SalesTerritory`: country and territory data.
- `Task`: original task requirements.
